# 界面重设计（v4：浅色 · 抽屉式）

SwiftUI 原生界面的下一版视觉与交互。本目录是**设计稿**，不是实现；实现时以本文和 `mockups/` 源文件为准，功能范围仍以 `docs/webui/` 的对照清单为准（本次只改呈现方式，不删功能）。

`mockups/*.dc.html` 每屏一个文件（390×844），HTML + 内联样式，颜色、尺寸、间距直接读源码即可。`{{…}}`、`<sc-for>`、`<sc-if>` 是模板占位与循环 / 条件，数据在文件末尾 `renderVals()` 里。

稿里的会话标题、文件名、数字都是示意数据。

## 1. 原则

- **打开就能干活**：启动直接是新对话，历史收进左侧抽屉，不再先进列表。
- **一屏一个重点**：不画卡片描边，不堆标签和横幅，靠留白分组。
- **单色**：黑 / 白 / 灰。颜色只用在两处——状态小圆点（运行中、等待允许）和代码改动的增删。
- **次要操作往里收**：模型、权限、附件在输入框里；文件、终端、改动、上下文在工作台；插件、自动化、引擎在设置。

## 2. 信息架构（与现状的差异）

| 现状（`MainView` / `SessionListView`） | 新设计 |
|---|---|
| `NavigationSplitView`，iPhone 上先进会话列表 | iPhone：根视图就是对话（无选中时显示「新会话」空状态）；会话列表放进从左侧滑出的**抽屉** |
| 左上「⋯」菜单里藏着设置 / 插件 / 自动化 / 网页版 | 抽屉底部「设置」入口（附引擎状态）；插件、自动化在设置里 push 进入；「网页版」放到设置最底部（DEBUG 对照用） |
| 会话右上「⋯」菜单：文件 / 终端 / 用量 + 重命名等 | 右上一个**工作台**按钮 → 全屏 sheet，页签「终端 / 文件 / 改动 / 上下文」；重命名 / 复制为新会话 / 归档改为长按标题或抽屉里长按会话 |
| 顶部标题 = 会话名 | 顶部中间 = **会话名**，点开是会话菜单（空白新会话显示模型）；模型在输入框的「+」托盘里 |
| 审批 / 提问卡片堆在输入框上方 | 审批是底部弹出的**半屏 sheet**（背景压暗）；提问（QuestionCard）同样形式 |

iPad（regular 宽度）保留常驻侧栏：抽屉内容直接作为 `NavigationSplitView` 的 sidebar，其余不变。

## 3. 设计 token

字体：iOS 用系统字体（SF Pro / 苹方），稿里的 Inter + Noto Sans SC 只是替身；代码 / 命令用 SF Mono（稿里是 JetBrains Mono）。

| 用途 | 浅色 | 深色（跟随系统时） |
|---|---|---|
| 背景 | `#FFFFFF` | `#0C0C0D` |
| 主文字 / 主按钮底 | `#0C0C0D` | `#F2F2F3` |
| 主按钮上的图标/字 | `#FFFFFF` | `#0C0C0D` |
| 次要文字 | `#6B6B72` | `#9A9AA0` |
| 弱图标（箭头、终端提示符） | `#A3A3AA` | `#6E6E74` |
| 输入框底、命令块底 | `#F3F3F4` | `#1A1A1C` |
| 分组列表底、终端底 | `#F5F5F6` | `#141416` |
| 用户气泡、搜索框、选中行 | `#ECECEE` | `#222225` |
| 次要按钮底（拒绝 / 重启） | `#E5E5E8` | `#2A2A2E` |
| 描边（建议 chip、未选中开关 chip） | `#E3E3E6` | `#2E2E32` |

| 状态：等待允许 | `#D98A00` | `#F5A524` |

建议放进 `Assets.xcassets` 的 Color Set（Any / Dark 两套），视图里只用语义名。

字号：大标题 28 粗；正文 / 列表 16；次要 13–14；工具与命令 13 等宽。行高正文约 1.7。

圆角：输入框 28；审批 sheet 36；分组列表 / 终端 22–28；按钮与 chip 用胶囊（高度一半）。点按区域不小于 44pt。

## 4. 各屏

### 4.1 新会话（`mockups/Main.dc.html`）
- 顶栏：左「两道横线」开抽屉；中间模型选择器，显示完整型号（如 `DeepSeek-V4.1-Flash`），有推理档位时在下面一行标出；右侧留空。
- 中部：标题「探索未至之境」（与官方 Web 的 `hero.headline` 一致）+ 当前**工作区 chip**（点开切换，对应 `AppModel.workspaces`）+ Agent 预设 chip。
- 输入框上方一行**建议任务** chip，横向滚动；点一下即填入并发送。内容可先写死几条，后续接斜杠指令或最近用过的提示。
- 输入框（见 4.7）。

### 4.2 抽屉（`mockups/Drawer.dc.html`）
- 从左边缘右滑或点左上按钮打开，宽约 326pt，右侧露出压暗的对话，点它或左滑关闭。
- 顶部：搜索框 + 视图菜单；下面一整行**新会话**描边按钮（对齐官方 Web 侧栏，新建会话不藏在图标里，但不抢会话列表的视觉重心）。
- 两行入口：当前工作区（「切换」）、自动化（数量）。
- 会话默认按工作区分组，可切到按「今天 / 本周 / 更早」分组；每行只有标题；运行中显示绿点、等待审批显示橙点；当前会话行用浅灰底。还没发消息的空白会话不进列表，发出第一条才出现。保留现有左滑置顶 / 右滑归档 / 长按菜单。
- 底部：设置入口，副标题显示引擎状态。

### 4.3 对话（`mockups/Conversation.dc.html`）
- 顶栏：抽屉按钮 / 新会话按钮 / 会话名（点开：重命名、分叉、归档、导出日志）/ 工作台按钮。有后台任务、子智能体、提醒时多一个入口，多于一项收进「⋯」。
- 用户消息：右对齐浅灰气泡，圆角 22。
- 工作步骤（process group）默认折叠成一行灰字「完成 N 个步骤 · 用时」，点开显示 44pt 的工具行；点行打开详情 sheet，长按复制；运行中改为「正在…」+ 当前工具名。
- 助手回复：正文直接铺开，不加气泡。
- 本轮有文件改动时，回复后出现一行轻入口「改动了 N 个文件 +a −b」，点开工作台的「改动」页。
- 回复下不放操作行：长按整轮回复出菜单（复制、选择文本、重新生成、从这里分叉、用量）。
- 输入框上方最多一条状态条（任务进度、等你允许、排队数），点开是 sheet；上下文只在 80% 以上才提示。

### 4.4 审批（`mockups/Approval.dc.html`）
- 底部弹出白色 sheet，背后不压暗，可滚动查看上文；到来时收起键盘，输入框暂不可点。
- 标题「允许运行这条命令？」+ 两行理由（点开看全文）+ 等宽命令块（放不下就滚动，必须能看全）。
- 两个等宽胶囊按钮：「拒绝」（灰）「允许」（黑）。
- 多个待审批时依次弹出，标题旁显示 1/3；抽屉里对应会话显示橙点。

### 4.5 工作台（`mockups/Workbench.dc.html`，四个页签由 `state.tab` 切换）
- 从对话右上进入的全屏 sheet，顶部胶囊页签：终端 / 文件 / 浏览器 / 改动 / 上下文，右上关闭。打开时不弹键盘。
- 终端：全宽贴边，轻点才聚焦；底部一行可横滑的 44pt 快捷键（esc / tab / ctrl / ↑ / ↓ / ← / → / | / - / ~ / 粘贴）。
- 文件：分组列表，修改过的文件标「已修改」。
- 改动：一级是文件列表（+a −b），点进单文件 diff（增删行底色见 token）。
- 上下文：大号百分比 + 细进度条 + 缓存命中 / 输入 / 输出三行 +「压缩上下文」按钮（对应 `UsageView` 的数据）。

### 4.6 设置与插件（`mockups/Settings.dc.html`、`mockups/Plugins.dc.html`）
- 设置：大标题 + 右上关闭。顶部引擎卡片（状态点、运行时长、内存、「重启」）；分组：模型（账号、默认模型、访问模式）/ 扩展（插件、自动化）/ 通用（外观、存储、引擎日志）。
- 插件：顶部若有待重启的变更，显示一行提示 + 黑色「重启」；列表每行名称 + 一行说明 + 开关（开 = 黑轨白钮）；iOS 不可用的插件置灰并说明原因；底部一句说明 iOS 执行层插件始终启用。

### 4.7 输入框（所有对话屏共用）
- 圆角 28 的浅灰整块，单行：左「＋」、中间输入、右主按钮。新会话空状态与对话中完全一致（早期稿里空状态展开成两行，已改为统一）。
- 「＋」托盘：相机 / 照片 / 文件、引用、指令、模型、计划模式、「思考」开关、访问模式（现有 `/permission`）。模式类不常改，不占输入框的位置；计划模式开着时显示在输入框上方的状态条里（键盘弹起时让位，占位文字变成「描述任务」）。
- 右侧主按钮状态：
  - 空输入 → 语音（未实现前改为置灰的发送按钮）；
  - 有输入 → 黑色发送；
  - 运行中且空输入 → 停止；
  - 运行中且有输入 → 发送 = 排队，长按 = 立即插话（沿用现有逻辑）。
- 排队中的消息显示在输入框上方一行灰字，可「立即插话」。

## 5. 实现建议

- 先做 token（Color Set + 少量 `ViewModifier`：胶囊按钮、分组列表、状态点），再按屏替换。
- 结构改动集中在 `MainView`（根视图 + 抽屉）、`SessionListView`（变为抽屉内容）、`ConversationView`（顶栏、步骤折叠、动作行、审批 sheet）、`ComposerView`（新输入框）；`TerminalView` / `FilesView` / `UsageView` 合并进新的工作台 sheet。
- 不改 `Core/` 和 `Models/` 的协议层；需要新数据（如改动统计）先查 `docs/webui/` 里对应的 RPC。
- DEBUG 的 `-dshOpen` 参数补上 `drawer`、`workbench`，方便截图对照。

## 6. 验收

- iPhone 15 / SE 两种尺寸下，各屏与 `mockups/` 设计稿在布局、层级、配色上一致。
- 浅色 / 深色跟随系统切换正常，对比度满足 WCAG AA（次要文字 ≥ 4.5:1）。
- 现有功能都还能用：发送 / 排队 / 插话 / 停止、审批、提问、模型与权限切换、置顶 / 归档 / 重命名 / 复制为新会话、文件、终端、用量、设置、插件、自动化。
- 长会话滚动不回退。

## 7. App 图标与启动屏

- **图标**：吉祥物大肥鱼的头像：蓝发、鲸鳍、女仆头饰，眨眼笑。形象基于社区鲸鱼娘，图片按 CC BY-NC-SA 4.0 使用，不适用项目的 MIT 协议（见 `THIRD_PARTY_NOTICES.md`），也不使用 DeepSeek 官方 Logo。图标和启动图由 `brand/make-icons.py` 从 `brand/mascot-icon.png` 生成。
- **启动屏**：`Info.plist` 的 `UILaunchScreen` = 背景色 `Background` + 居中的 `LaunchMark`（同一图形，浅色墨色 / 深色浅灰两套）。引擎启动期间 `StartupView` 保持同一图形在同一位置，只在下方加一行进度，避免闪跳。
- **重新生成**：`swiftc -O docs/design/brand/render-icon.swift -o /tmp/render-icon && /tmp/render-icon app/DshIOS/Assets.xcassets`。
